# Catalogue des blocs Minecraft (Java 26.3)

Tous les blocs posables, rangés par catégorie puis par famille. Chaque bloc s’écrit `"t": "mc:<id>"`, sauf les **variantes** de composants (portes, trappes, boutons, plaques, rail) qui s’écrivent avec le type de base et `"id"` : voir la fin de ce fichier.

Pour chercher un bloc par son nom français ou anglais sans lire ce fichier : `python3 scripts/blueprint.py find chêne`.

## Familles

| Famille | Comportement dans le planificateur |
|---|---|
| `cube` | bloc plein opaque : conduit, porte poudre/torches |
| `cubefix` | bloc plein opaque, non poussable |
| `clear` | transparent : porte la poudre, ne conduit pas |
| `clearfix` | transparent, non poussable |
| `plant` | plante : sol plein, terre labourée ou chemin en dessous |
| `flat` | plat au sol : bloc plein en dessous |
| `slab` | dalle basse : ne porte rien |
| `stairs` | escalier : f = côté haut |
| `post` | barrière / muret / vitre |
| `misc` | décoratif, ne conduit pas |
| `miscfix` | utilitaire, non poussable |
| `miscbreak` | fragile, cassé par un piston |

Seuls `cube` et `cubefix` conduisent le signal (comme `solid`). Pour porter de la poudre, un répéteur ou une torche posée dessus, il faut un bloc avec un dessus plein : `cube`, `cubefix`, `clear`, `clearfix` ou un bloc de base plein.
